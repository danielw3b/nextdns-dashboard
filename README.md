# NextDNS Live Viewer

A lightweight, zero-dependency Progressive Web App (PWA) providing real-time telemetry, live DNS query streaming, analytics, and custom guardrails for NextDNS profiles.

🌐 **Live App:** <https://nextdns-dashboard-e3q.pages.dev/>

## 📸 Preview

## ✨ Features

* ⚡ **Live Query Stream:** Real-time monitoring of DNS queries with fast domain and device filtering.

* 📊 **Real-Time Analytics:** Visual breakdown of allowed vs. blocked queries, query types, latency, and client IPs.

* 🛡️ **Autonomous Guardrails:** Track hit rates per domain and enforce automatic block rules.

* 🔒 **Privacy-First:** Pure client-side application. Credentials and logs stay inside your browser.

* 🧪 **Built-in Demo Mode:** Test features instantly with simulated traffic when API credentials are omitted.

## 🚀 Quick Start

1. Open <https://nextdns-dashboard-e3q.pages.dev/> in any modern browser.

2. Navigate to the **Configuration** tab.

3. Enter your **NextDNS Profile ID** and **API Key**.

4. Save configuration to switch from **Demo** mode to **Live** telemetry streaming.
